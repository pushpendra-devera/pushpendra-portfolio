## What this repository demonstrates

This public fork is useful as an integration reference rather than as an
original product claim. Its library surface shows how a host Android
application can provide payment parameters, obtain a checkout ID from its own
server, configure the native Peach Payments/OPPWA checkout, and receive a
compact success or failure callback.

## Verified payment flow

The source validates amount, currency, transaction type, environment, and the
server URL. It then obtains the checkout identifier asynchronously, enables
Visa, Mastercard, and SEPA Direct Debit, turns on WebView support for 3-D
Secure, launches the SDK checkout activity, and handles completion,
cancellation, SDK errors, and the asynchronous callback path.

## Why it remains a supporting project

The implementation is old, the live environment condition contains a defect,
and the Git history is entirely upstream-authored. Keeping it as a small,
accurately labelled reference demonstrates payment-flow analysis without
overstating ownership or current production readiness.
