## Overview

LocalVodSaudi is prior React Native media work spanning video discovery and
playback, podcasts, audio, profiles, recommendations, and push notifications.
The project is included as representative mobile-delivery experience rather
than a source-reviewed case study because its private implementation is not
available in this portfolio workspace.

## Contribution

The work covered cross-platform feature implementation and the boundaries where
media behavior differs between Android and iOS. It also connected content
consumption with user profiles, recommendations, and Firebase-backed
notifications.

The public description deliberately excludes user data, private screenshots,
client internals, and numerical usage or reliability claims that have not been
independently corroborated.
