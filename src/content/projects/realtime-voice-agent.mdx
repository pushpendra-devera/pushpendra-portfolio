## Overview

This prototype explores a mobile voice agent that can switch between Hindi and
English and keep conversational latency low through OpenAI's Realtime API. The
React Native client owns the push-to-talk experience, while the Express server
keeps the long-lived provider key out of the app and returns only short-lived
session credentials.

## Prototype scope

The architecture has two voice paths: WebRTC for realtime conversation and an
HTTP/SSE pipeline that composes transcription, response generation, and speech.
The latter is implemented but is not yet connected to the main UI's failure
path, so this page deliberately describes the project as a prototype rather
than a finished voice product.
