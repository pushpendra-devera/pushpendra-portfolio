## Overview

I built ChatGPT Assist to explore how several generative-AI interactions feel
inside one mobile product rather than as isolated API demos. The result is a
drawer-navigated React Native app with three working paths: a conversation with
message history, DALL·E 3 image generation, and device audio recording followed
by Whisper transcription.

## What this demonstrates

The useful part of this project is the mobile integration work around the model
calls: recording and uploading device audio, coordinating asynchronous loading
and error states, sharing a user-provided credential across screens, and
rendering different output types inside a consistent navigation structure.

The source is public, and the limitations below are intentional disclosure. I
would move all provider access behind a backend boundary before treating this
as a production architecture.
