## Overview

This experiment replaces a standard dark-mode switch with a small WebGL scene.
A sun and moon share the scene, and a click changes theme state while the render
loop interpolates their visibility.

Its portfolio value is intentionally narrow: it demonstrates direct Three.js
scene setup, animation, and React integration. The limitations document the
lifecycle work that would be required before reusing the approach in a larger
application.
