## Overview

This major project is a complete college-management workflow built with Django.
It uses one email-based login system and directs HOD, staff, and student users to
different portals backed by a shared academic data model.

## Role coverage

**HOD / administrator:** manages staff, students, courses, subjects, and
sessions; reviews attendance; approves or rejects leave; and responds to
feedback.

**Staff:** records and updates attendance, submits leave and feedback, maintains
a profile, and enters exam and assignment results.

**Student:** reviews attendance and results, applies for leave, submits
feedback, and maintains a profile.

The project is useful evidence of full-stack and relational application work,
but it remains labelled as an academic build because it does not have production
release or operational evidence.
