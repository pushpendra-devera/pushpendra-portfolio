## Overview

Dallal is a bilingual (English/Arabic) real estate marketplace app for the
Kuwait market, built in React Native for Android and iOS. It covers property
search, listings, in-app messaging and calling, broker/civil-ID verification,
maps, and analytics, and is published on both the App Store and Google Play.

## Context

The app needed to work as one coherent product across two languages with
different reading directions (LTR English, RTL Arabic), support real-time
voice/video calls that stay reliable no matter what state the app is in on
the device, and grow its API surface (the client integration eventually
covered 100+ REST endpoints) without each new endpoint reinventing auth and
retry handling.

A multi-step property listing flow was also part of the product: address
autofill (PACI), OCR-based civil ID parsing for verification, AI-generated
listing descriptions, media upload, and validation, instrumented with 30+
analytics events to track usage through that flow.
